Every command works on a remote machine. The name comes first.

Scheduled

A job runs on a machine you own, on a schedule you set, whether or not your laptop is open. The daemon runs it, not your terminal.

Secrets stay put

API keys and tokens are encrypted at rest on the machine that uses them, keyed from its own identity. Readable from the command line, from scripts, and by your AI tool, never in plaintext on disk.

Calls any API

Scripts get a fetch-style HTTP client with bearer tokens pulled straight from the secrets store. No curl, no dependencies, no third-party automation service holding your keys.

Capabilities

Ready-made jobs you switch on with one command: a health monitor, a security baseline, fleet-wide log search, Gmail triage with a morning briefing. The list.

Keeps its own state

A key-value store and time series on every machine, so a job can remember what it saw last time and you can query the result later.

Morning briefing in three commands

From zero to AI-triaged email, every morning, on a machine you own.

Store the credentials

Encrypted on the remote machine. They never leave it in plaintext.

$ hop myserver secrets set ANTHROPIC_API_KEY sk-ant-...

Switch it on

Registers the schedule, wires up the script, and starts it.

$ hop myserver cap enable email-monitor Enabled: email-monitor (daily 7 AM)

Wake up to a briefing

Unread mail sorted into urgent, action and FYI. Routine mail marked read. Or run it now.

$ hop myserver cap run email-monitor Briefing sent. 23 emails: 2 urgent, 5 action, 16 marked as read.

The Gmail side needs a one-time OAuth setup. The walkthrough and the script itself are in the docs: email monitor setup.

From your AI tool
