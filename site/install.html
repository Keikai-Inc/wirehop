Install

One command downloads the right binary, checks its signature, and puts hop on your path. No account, nothing to configure.

macOS (Apple Silicon and Intel) · Linux (x86_64, ARM64, ARMv7) · about 5 MB

Two kinds of machine

The same script installs both. One flag decides which.

Your laptop: a client

Reaches the machines you are invited to. No sudo, no background service.

$ curl -fsSL https://wirehop.org/install.sh | bash

A machine you want to reach: a host

An always-on service (needs sudo), reachable across reboots, with a name like myserver.hop.

$ curl -fsSL https://wirehop.org/install.sh | bash -s -- --host $ hop invite # then let a machine in

Build your command

Paste an invite and the command joins that machine's network on first run.

$ curl -fsSL https://wirehop.org/install.sh | bash

Advanced options

Client: reach hosts you're invited to, no sudo, no daemon. Join the network later with hop connect <invite>.

macOS

Apple Silicon and Intel. Also available as a signed and notarized .pkg.

Linux

x86_64, ARM64 and ARMv7. Static binaries, so the age of your distribution does not matter; the only floor is kernel 2.6.27. Tested distributions.

Windows

As a client under WSL today. A native client is planned; a Windows host is not yet.

Prefer not to pipe a script into your shell?

Every release is also published as plain, signed files.

GitHub Releases

A plain binary per platform, with a .sha256 and an RSA .sig beside each one, plus the macOS .pkg. Latest release.

npm

npx -y @wirehop/wirehop downloads the same signed binary and verifies it before installing. This is also how AI tools usually run it.

Check it yourself

The installer verifies every download against the release key before it runs anything. The key is wirehop-release.pub; the same key is embedded in the install script.

$ curl -fsSLO https://github.com/Keikai-Inc/wirehop/releases/latest/download/hop-linux-x86_64 $ curl -fsSLO https://github.com/Keikai-Inc/wirehop/releases/latest/download/hop-linux-x86_64.sig $ curl -fsSLO https://wirehop.org/wirehop-release.pub $ openssl dgst -sha256 -verify wirehop-release.pub -signature hop-linux-x86_64.sig hop-linux-x86_64 Verified OK
